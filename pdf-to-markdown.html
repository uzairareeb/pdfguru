Frequently asked questions

How are headings detected?

Lines set in noticeably larger type than the body text are treated as headings. It's heuristic, so check the result on unusual layouts.

Are tables and images converted?

Tables become plain text lines and images are skipped — this tool focuses on clean, readable text.

Why would I want Markdown?

It's perfect for note apps, documentation sites, and as clean input for AI assistants.
